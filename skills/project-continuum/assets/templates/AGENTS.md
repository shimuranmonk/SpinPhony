# Project operating instructions

Before editing, verify repository, branch, revision and worktree. Read [continuation](docs/CONTINUATION.md), then the relevant [handover](docs/HANDOVER.md) section. Preserve existing work. Use repository evidence when recorded status is stale. Continue only authorized scope.

At meaningful checkpoints, update continuation and affected records. Cite approvals and test evidence. Keep pending checks explicit. Follow the project Git workflow and verify publication before reporting it.

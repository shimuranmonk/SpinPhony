# SpinPhony — Soundtrack of a Loop

SpinPhony turns a song into a table tennis practice session. It exports an MSYNC v1 file for **Nova Prime**, a controller for the **PONGBOT Nova S Pro**. Audio stays in your browser. Keep the original track to use with the export.

- **Music** — Pick a track, choose Nova or saved Custom drills, and generate a draft for your skill level, pace, and racket hand.
- **MSYNC Editor** — Place and edit drill, flavor, idle, and stop blocks. Drop yellow flags as bookmarks. Reuse drill definitions, save patterns for later, and validate the file.
- **Preview** — Play the song, jump to cues on the map, and download the current score.

## Help us improve Auto

Auto gives you a starting point. It can miss musical changes or lean too heavily on one drill. Where would you place the drills and rests? Which musical events should SpinPhony detect, and which colors or labels would make those cues easier to spot? A track name and a few timestamps would help. [Share a suggestion](https://github.com/shimuranmonk/SpinPhony/issues/new).

## Run locally

With Node.js 20.19+ or 22.12+, run `npm ci` and `npm run dev`.
